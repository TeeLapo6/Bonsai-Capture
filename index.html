Get started with the unpacked alpha

This alpha is meant to be built locally and loaded into Chrome or Brave as an unpacked extension.

1

Clone or download

Get the source from GitHub so you can build the extension locally.

2

Build the extension

Run npm install and npm run build.

3

Load unpacked

Open chrome://extensions, enable Developer mode, and select dist/.

4

Capture and export

Use the side panel to capture chats and artifacts, then export to Markdown, JSON, or TOON.
